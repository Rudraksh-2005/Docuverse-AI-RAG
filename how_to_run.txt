🚀 Running Locally

---
**🛠️ ONE-TIME SETUP (You only do this once!)**
---

1️⃣ Clone Repository
git clone https://github.com/Rudraksh-2005/Docuverse-AI-RAG.git
cd Docuverse-AI-RAG

2️⃣ Create Virtual Environment
python -m venv venv

3️⃣ Install Dependencies
Windows:
venv\Scripts\activate
pip install -r requirements.txt

Linux / Mac:
source venv/bin/activate
pip install -r requirements.txt

4️⃣ Create Environment File
Create a .env file in the project root.
GROQ_API_KEY=your_groq_api_key
Get your API Key from: https://console.groq.com/keys


---
**▶️ EVERY TIME YOU WANT TO RUN THE APP**
---

There are two ways to start the app:

🟢 Method 1: The Easy Way (Windows)
Just double-click the `run.bat` file in the project folder!

🟢 Method 2: Manual Terminal Commands
1. Open a terminal in the project folder
2. Activate environment: `venv\Scripts\activate`
3. Run the backend: `python -m uvicorn backend.main1:app --reload`

Once the server is running, open your browser and go to:
http://127.0.0.1:8000
